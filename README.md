# CT Havan Costa

Sistema de gerenciamento de alunos para uma escolinha de futevôlei, desenvolvido em Java.

![Java](https://img.shields.io/badge/Java-25-orange)
![Status](https://img.shields.io/badge/Status-Em%20desenvolvimento-blue)

## Sobre o projeto

O CT Havan Costa é um projeto desenvolvido com o objetivo de praticar programação Java e conceitos de orientação a objetos, criando um sistema simples para gerenciar alunos e suas mensalidades.

## Funcionalidades

- Cadastro de alunos
- Listagem de alunos
- Consulta de faturamento mensal
- Busca de alunos por nome
- Busca por valor de mensalidade
- Identificação da maior mensalidade
- Listagem dos alunos que pagam a maior mensalidade
- Validação de dados no cadastro
- Identificação de nomes duplicados, ignorando acentos e diferenças entre maiúsculas e minúsculas

## Tecnologias utilizadas

- Java 25
- IntelliJ IDEA
- Git
- GitHub

## Estrutura do projeto

- `Main.java`: menu principal e interação com o usuário.
- `Aluno.java`: representação dos alunos.
- `GerenciadorAlunos.java`: gerenciamento dos cadastros, buscas e cálculos.

## Como executar

1. Clone este repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Configure o JDK 25.
4. Execute o arquivo `Main.java`.
